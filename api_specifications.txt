1. GET /products

Описание:
Получение списка всех товаров
Параметры:
Не нужны
Тело запроса:
Не нужно
Успешный ответ:
200 ОК
Ошибки:
500 Internal Server Error - ошибка сервера
Пример запроса:
GET /products HTTP/1.1
Host: sfmshop.com
Accept: application/json
Пример ответа:
HTTP/1.1 200 OK
Content-Type: application/json
[
  {
    "id": 1,
    "name": "Ноутбук",
    "price": 50000,
    "quantity": 10
  }
]

2. GET /products/{id}

Описание:
Получение товара по id
Параметры:
id - идентификатор товара
Тело запроса:
Не нужно
Успешный ответ:
200 ОК
Ошибки:
400 Bad Request - некорректный id товара
404 Not Found - товар с таким ID не найден
500 Internal Server Error - ошибка сервера
Пример запроса:
GET /products/3 HTTP/1.1
Host: sfmshop.com
Accept: application/json
Пример ответа:
HTTP/1.1 200 OK
Content-Type: application/json
  {
    "id": 3,
    "name": "Клавиатура",
    "price": 5000,
    "quantity": 6
  }

3. POST /products

Описание:
Создание товара
Параметры:
Не требуется
Тело запроса:
{
    "name": "Коврик для мыши",
    "price": 1000,
    "quantity": 10
}
Успешный ответ:
201 Created
Ошибки:
400 Bad Request - неправильные данные
500 Internal Server Error - ошибка сервера
Пример запроса:
POST /products HTTP/1.1
Host: sfmshop.com
Content-Type: application/json

{
    "name": "Коврик для мыши",
    "price": 1000,
    "quantity": 10
}
Пример ответа:
HTTP/1.1 201 Created
Content-Type: application/json
{
  "id": 4,
  "name": "Коврик для мыши",
  "price": 1000,
  "quantity": 10
}

4. PUT /products/{id}

Описание:
Обновление товара по id
Параметры:
id товара который нужно обновить
Тело запроса:

{
    "name": "Коврик для мыши большой",
    "price": 1200,
    "quantity": 20
}
Успешный ответ:
200 OK
Ошибки:
400 Bad Request - неправильные данные
500 Internal Server Error - ошибка сервера
404 Not Found - товар не найден
Пример запроса:
PUT /products/4 HTTP/1.1
Host: sfmshop.com
Content-Type: application/json

{
    "name": "Коврик для мыши большой",
    "price": 1200,
    "quantity": 20
}
Пример ответа:
HTTP/1.1 200 OK
Content-Type: application/json

{
    "id": 4,
    "message": "Товар успешно обновлён"
}

7. POST /orders

Описание:
Создать заказ
Параметры:
Не требуются
Тело запроса:
{
  "user_id": 3,
  "product_id": 4,
  "quantity": 2
}
Успешный ответ:
201 Created
Ошибки:
400 Bad Request - неправильные данные
404 Not Found - пользователь или товар не найден
500 Internal Server Error - ошибка сервера
Пример запроса:
POST /orders HTTP/1.1
Host: sfmshop.com
Content-Type: application/json
{
  "user_id": 3,
  "product_id": 4,
  "quantity": 2
}
Пример ответа:
HTTP/1.1 201 Created
Content-Type: application/json

{"id": 5, "user_id": 3, "product_id": 4, "quantity": 2, "total": 3000}
