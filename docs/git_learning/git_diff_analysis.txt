Анализ изменений между ветками:

1. feature/add-logging
В ветке feature/add-logging добавлен файл src/utils/logger.py.
В файл были добавлены функции для базового логирования:
- log_info(message)
- log_error(message)

2. feature/add-caching
В ветке feature/add-caching добавлен файл src/utils/cache.py.
В файл были добавлены функции для базового кэширования:
- get_cache_key(key)
- clear_cache()

3. Сравнение с main
Ветка main не содержит изменений, связанных с логированием и кэшированием.
Обе feature-ветки были созданы независимо от main и содержат отдельные коммиты под свои задачи.

4. Вывод
Изменения в ветках изолированы и не пересекаются.
Это соответствует нормальному workflow, где каждая новая функция разрабатывается в отдельной feature-ветке.
