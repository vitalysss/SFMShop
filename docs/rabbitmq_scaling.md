# Масштабирование RabbitMQ Consumer

Для равномерного распределения задач используется: 
channel.basic_qos(prefetch_count=1)

prefetch_count=1 означает что Rabbit не отправляет консьюмеру новую задачу,
пока предыдущая не подтвердится ACK. Это поможет распределить сообщения
между несколькими консьюмерами равномерно 

## Запуск нескольких consumer
Чтобы запустить несколько консьюмеров, нужно открыть несколько терминалов и
выполнить команду python src/services/queue_consumer.py в каждом.
Все консьюмеры слушают очередь order_processing, а Rabbit распределяет сообщения
между доступными. Это позволяет масштабировать систему горизонтально.
