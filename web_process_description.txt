6 этапов процесса загрузки сайта:
1. DNS-запрос - это когда браузер преобразует имя сайта в IP-адрес сервера
   По времени такой запрос занимает 10-50мс.
   Проблема может быть в медленном DNS.
2. Установка TCP-соединения - браузер устанавливает соединение с IP-адресом сервера
   По времени такой запрос занимает 50-200мс.
   Проблема может быть в соединении с сетью, неправильном запросе
3. HTTP-запрос, после установки соединения браузер отправляет запрос на получение данных
    в запросе есть метод GET, путь (куда конкретно нужно перейти на сайте), например, /products
    и заголовок Host
    100-500мс
    Проблема может быть в неправильном запросе или сетевой задержке
4. Обработка на сервере, сервер получает запрос, определяет какие данные нужны для обработки
   и выполняет код обработчика
   100-500мс
   Проблема может быть в медленном коде или медленных запросов к БД или большой нагрузке на сервер
5. HTTP-ответ, сервер отправляет ответ браузеру со статусом и данными
   100-500мс
   Проблема может быть в слишком большом размере ответа или медленной передачи данных по сети
6. Рендеринг в браузере, то есть отображение ответа пользователю, примерно 50-200мс
   Проблема может быть в медленном отображении данных или тяжелом интерфейсе
